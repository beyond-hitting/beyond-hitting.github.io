# Project Page for Beyond Hitting

Project page for **Beyond Hitting: Learning Diverse Humanoid Badminton Skills with Targeted Return Control**.

## Local preview

From this folder, run

```bash
python3 -m http.server 8000
```

and then open `http://localhost:8000`.
